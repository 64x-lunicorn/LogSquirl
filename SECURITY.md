# Security Policy

## Supported Versions

Versions of LogSquirl that are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 26.03   | :white_check_mark: |
| < 26.03 | :x:                |

## Reporting a Vulnerability

To report security issues, please open a
[security advisory](https://github.com/64x-lunicorn/LogSquirl/security/advisories/new)
on GitHub (not for general support).


Reports are private: only the maintainers and the reporter see a security
advisory until a fix is published. Please do not open a public issue, pull
request or discussion for a vulnerability.

We aim to acknowledge a report within 14 days. A confirmed vulnerability is
fixed as soon as we can, and we aim to publish the fix within 60 days of the
report. The fixed release is announced in `CHANGELOG.md` under `## Security`,
with the CVE identifier when one was assigned, and reporters are credited
unless they prefer not to be.
