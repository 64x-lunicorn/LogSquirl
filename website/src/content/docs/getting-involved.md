## GitHub

Feel free to submit bug reports, feature requests, questions and pull requests on the [GitHub project](https://github.com/64x-lunicorn/LogSquirl).

## Documentation

Full documentation is available on the [LogSquirl Wiki](https://github.com/64x-lunicorn/LogSquirl/wiki), including Getting Started, feature guides, configuration reference, and plugin development.

## Chats with developers

There is a [Telegram group](https://t.me/joinchat/JeIBxstIfp4xZTk6) and [Gitter community](https://gitter.im/logsquirl_log_viewer/community).

## Plugins

LogSquirl supports plugins — see the [Plugin System](https://github.com/64x-lunicorn/LogSquirl/wiki/Plugin-System) wiki page and the [Plugin Development Guide](https://github.com/64x-lunicorn/LogSquirl/wiki/Plugin-Development).

Available plugins:
- [LogSquirl-Logcat](https://github.com/64x-lunicorn/LogSquirl-Logcat) — Android Logcat via ADB
- [LogSquirl-Serial](https://github.com/64x-lunicorn/LogSquirl-Serial) — Serial port monitoring
