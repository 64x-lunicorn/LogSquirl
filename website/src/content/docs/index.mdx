## Features

<CardGrid>
  <Card title="Open anything" icon="document">
    - Log Files of any size, read from disk instead of loaded into memory
    - Archives and compressed files: zip, 7z, tar, gz, bz2, xz, zst, lz4
    - Standard input: `journalctl -f | logsquirl -`
    - Follow a growing Log File as it is written
    - Automatic encoding detection, or pick one yourself
  </Card>
  <Card title="Search fast" icon="magnifier">
    - Regular expressions through Vectorscan and Hyperscan, SIMD-accelerated on every core, with PCRE as the fallback
    - Combine patterns with `and`, `or` and `not`
    - Search results in their own view, with context lines around each match
    - Keep several Searches of one file side by side
    - Limit a Search to a line or a time range
  </Card>
  <Card title="Understand" icon="list-format">
    - Log Formats recognized automatically, shown as a table with one column per field, JSON and logfmt included
    - Go to a timestamp, and see the time between lines
    - Chart Panel: plot values and message rates over time, and jump from a point to its line
    - Count the values of a column or a capture group
    - Highlighter Sets and nine Color Labels
  </Card>
  <Card title="Work your way" icon="setting">
    - Themes, Smyck and Smyck Light included, switched without a restart
    - Command Palette and fully configurable shortcuts, vi and less keys included
    - Tab groups, marks and sessions that restore where you left off
    - Team Folder: share Filter Groups and Highlighter Sets through a Git repository
    - Plugins for new sources and formats, such as Android Logcat and serial ports
    - Scratchpad with JSON, XML, Base64 and JWT tools; nine languages
  </Card>
</CardGrid>
